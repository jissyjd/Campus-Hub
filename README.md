# Campus Event Hub

React campus-fest event discovery and registration site, built with JavaScript, MUI, and Chart.js.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

Create a production build with `npm run build`. Vercel uses the included `vercel.json` to build the app and publish the `build` directory.

Event registration, demo checkout, and ticket downloads run in the browser. Demo checkout does not process real payments.
